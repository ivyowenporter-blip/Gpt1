# Playwright Session Gateway

A FastAPI service that exposes HTTP endpoints for creating short-lived Playwright browser sessions, navigating to URLs, interacting with selectors, extracting text, and capturing screenshots. The service is stateless aside from an in-memory session registry that enforces TTL-based cleanup.

## Features

- Launch Chromium, Firefox, or WebKit sessions on demand in headless or headed mode.
- Navigate to any URL and wait for configurable readiness states.
- Click CSS/XPath selectors with explicit timeout handling.
- Extract text content from the first or all matching elements.
- Capture page or element screenshots (returned as base64 strings).
- Close sessions explicitly or rely on the TTL-based cleanup to reclaim resources.

## Getting started

1. Install Python 3.10+ and the required dependencies:

   ```bash
   pip install -r requirements.txt
   playwright install
   ```

2. Run the FastAPI app with Uvicorn:

   ```bash
   uvicorn app.main:app --reload
   ```

3. Interact with the API via cURL, HTTPie, or the autogenerated Swagger UI at `http://localhost:8000/docs`.

## Example workflow

```bash
# Create a session
SESSION_ID=$(curl -s -X POST http://localhost:8000/sessions | jq -r '.session_id')

# Navigate to a page
curl -X POST "http://localhost:8000/sessions/$SESSION_ID/navigate" \
  -H "Content-Type: application/json" \
  -d '{"url": "https://example.org", "wait_until": "networkidle"}'

# Read the heading text
curl -X POST "http://localhost:8000/sessions/$SESSION_ID/text" \
  -H "Content-Type: application/json" \
  -d '{"selector": "h1", "all_matches": false}'

# Capture a screenshot (base64 encoded)
curl -X POST "http://localhost:8000/sessions/$SESSION_ID/screenshot" \
  -H "Content-Type: application/json" \
  -d '{"full_page": true}'

# Clean up
tmp=$(curl -X DELETE "http://localhost:8000/sessions/$SESSION_ID")
```

## Configuration

`SessionManager` supports two knobs, configurable inside `app/main.py`:

- `max_sessions`: the number of concurrent sessions to keep in memory.
- `session_ttl`: idle time in seconds before a session is automatically recycled.

Errors from Playwright are surfaced as `500` responses with the original error message to make debugging automation flows straightforward.
